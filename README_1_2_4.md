# Tanko 1.2.4 — hasło i motywy

- Logowanie: Tanko / Tankuj mądrze / Tanio i dobrze.
- Opis: „najlepsza stacja na Twojej trasie”.
- Ujednolicone tokeny kolorystyczne i kontrast ekranów: logowanie, start, dodawanie cen/OCR, ranking, profil, ustawienia, formularze, okna dialogowe, onboarding, odzyskiwanie hasła.
- Popup mapy celowo zachowuje jasne tło i ciemny tekst w obu motywach.
- Zmieniona wersja cache PWA.

## Wdrożenie
Wgraj zawartość ZIP do głównego katalogu repozytorium GitHub Pages, zastępując stare pliki. Supabase: bez zmian. W PWA zamknij i otwórz aplikację po aktualizacji.

## Weryfikacja
Sprawdź ręcznie na iPhone/Android/desktop: wszystkie zakładki, formularz OCR, popup mapy, wszystkie dialogi i oba motywy (w tym systemowy). Automatyczna kontrola składni nie zastępuje testów na urządzeniu.
